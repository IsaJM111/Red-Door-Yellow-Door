 # Red Door Yellow Door
A first-person exploration game inspired by the mysterious Red Door, Yellow Door experience.

Red Door Yellow Door is a first-person exploration game inspired by the surreal experience of the same name. Players navigate an unfamiliar environment filled with rooms, doors, and unexpected discoveries. Built with Unity. All original music and sound effects were composed and created specifically for this project.

# About

Explore a unique environment from a first-person perspective. As you move through the world, new rooms are discovered, creating an experience where exploration and curiosity drive progression. The game uses First-Person Exploration. Navigate the environment from a first-person perspective. Each new doorway leads to another unexplored room.
